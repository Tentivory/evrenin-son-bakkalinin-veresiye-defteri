# Evrenin Son Bakkalının Veresiye Defteri

> **UYARI:** Bu depo bir muhasebe yazılımı değildir. Evrenin kapanış protokolünde unutulmuş bir kasa fişidir.

## Bu şey nedir?

Evrenin ışıkları sönmeden önce açık kalan **son bakkal**ın veresiye defteri.  
Borçlar TL, dolar veya Bitcoin ile tutulmaz. Birim:

**IYE — Işık Yılı Ekmeği**

Yani bir somun ekmeği ışık hızıyla bir yıl taşımanın maliyeti. Kimse ödemez. Kimse sormaz. Defter yine de yazılır.

## Neden var?

Çünkü kasa kapandı, defter açık kaldı.  
Çünkü kütleçekimi hep çekiyor.  
Çünkü zamanın kendisi gecikmeli ödeme yapıyor.

## Çalıştırma

```bash
python3 defter.py
```

Beş rastgele müşteri gelir. Beş rastgele borç yazılır. Toplam çıkar. Tahsilat evrenin sonundan bir iş günü sonraya ertelenir.
